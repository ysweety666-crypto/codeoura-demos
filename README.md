## ما الذي في هذا المستودع

ملفات بناء جاهزة فقط — لا شيفرة مصدرية. مستودعات المنتجات نفسها تبقى خاصة.

## البيانات

كل ما يظهر في هذه النسخ مُختلَق بالكامل. لا تتصل بأي قاعدة بيانات، ولا تحمل
ملفاتها أي مفتاح أو رابط لأي نظام حقيقي. أي تعديل يجريه الزائر يبقى في
متصفحه ويختفي عند إعادة التحميل.

قبل كل نشر تمرّ ملفات البناء على فحص آلي يبحث عن روابط مشاريع ومفاتيح
وسلاسل اتصال، ويمنع النشر عند رصد أي منها.
